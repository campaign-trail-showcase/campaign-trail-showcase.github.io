# Campaign Trail Showcase

![Campaign Trail Showcase](https://raw.githubusercontent.com/campaign-trail-showcase/campaign-trail-showcase.github.io/main/static/images/banners/tct_banner.webp)

**Campaign Trail Showcase** (CTS) is a fork of [The New Campaign Trail](https://newcampaigntrail.com/) by Decstar which is based upon [The Campaign Trail](http://americanhistoryusa.com/campaign-trail/) by Dan Bryan, and is updated to include new features.

For guidance on how to get your mod into the Showcase, see [How to Get Your Mod in The Showcase](How%20Tos/How%20to%20Get%20Your%20Mod%20in%20The%20Showcase.md).
